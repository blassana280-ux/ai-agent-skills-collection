# Contributing to AI Skills Collection

Thank you for considering contributing to the **AI Skills Collection**! This repository thrives on community contributions to provide the best, free, open-source library of AI Agent Skills, system prompts, persona instructions, and technical workflows.

---

## 🌟 How You Can Contribute

1. **Add New Skills**: Submit new agent skills, specialized prompts, or AI agent workflow guides.
2. **Improve Existing Skills**: Fix outdated instructions, improve formatting, add examples, or optimize trigger conditions.
3. **Organize & Categorize**: Suggest new categories, fix misplaced skills, or improve repository structure.
4. **Documentation**: Enhance the README, add integration guides, or share usage tips.

---

## 📁 Repository Structure

Place your Markdown skill files (`.md`) into the most relevant subcategory under one of the 5 main directories:

- 🧠 `AI-and-Automation/` (`AI-Agents`, `Data`, `LLMs`, `Machine-Learning`, `Prompts`, `RAG`)
- ☁️ `Cloud-DevOps-and-Security/` (`CI-CD`, `Cloud`, `Compliance`, `Infrastructure`, `Monitoring`, `Security`)
- 📈 `Marketing-and-Growth/` (`Ads`, `Analytics`, `Branding`, `Content`, `Copywriting`, `Email`, `Funnels`, `SEO`, `Social-Media`)
- 💼 `Product-and-Business-Operations/` (`Business`, `Operations`, `Product`, `Specs`)
- 💻 `Website-and-App-Development/` (`APIs`, `Backend`, `Databases`, `Frontend`, `Mobile-Apps`, `QA`, `Testing`, `UI-UX-Design`)

---

## ✍️ Skill Formatting Guidelines

To keep the collection clean and easy for AI assistants (Claude, Cursor, Codex, Gemini, ChatGPT) to parse, follow this standard structure:

```markdown
# Skill Name: [Descriptive Name]

## Description / Trigger
Explain what this skill does and when an AI assistant should activate it.

## Key Capabilities & Instructions
1. Step-by-step guidance
2. Best practices and rules
3. Required patterns

## Examples / Code Snippets
Provide concrete markdown or code examples.
```

---

## 🚀 Pull Request Process

1. **Fork the Repository**: Create your own copy of the repo on GitHub.
2. **Create a Branch**:
   ```bash
   git checkout -b feature/add-new-skill-name
   ```
3. **Add or Edit Skills**: Keep filenames descriptive, hyphenated, and lowercase (e.g. `react-19-features.md` or `database-designer-v3.md`).
4. **Commit & Push**:
   ```bash
   git commit -m "feat: add new AI agent skill for [Topic]"
   git push origin feature/add-new-skill-name
   ```
5. **Open a Pull Request**: Describe your changes and reference any related issues.

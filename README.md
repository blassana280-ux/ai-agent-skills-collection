## 🚀 How to Use These Skills

Each skill file is written in clean, structured **Markdown (`.md`)**. You can easily integrate them into your favorite AI tool or workflow:

### 1. **Cursor IDE**
- Copy the content of any `.md` file into your `.cursorrules` file or custom rule configuration in Cursor settings.
- Or attach the `.md` file directly in Cursor Chat using `@file`.

### 2. **Claude / Anthropic Agents**
- Add skill files into your project's `.claude/skills/` directory.
- Or reference them directly in system prompts or user context windows.

### 3. **ChatGPT / Custom GPTs**
- Copy instructions into **Custom Instructions** or the **Instructions** box when building a Custom GPT.

### 4. **Gemini CLI / Antigravity IDE**
- Place skills into your `.gemini/config/skills/` directory or reference them during active pair-programming sessions.
